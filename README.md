# WASCOTEXTIL

Commerce-Website für WASCOTEXTIL GmbH, Paderborn — Textilveredelung mit Digitaldruck, Flex, Flock und Stick.

Live: [wascotextil.vercel.app](https://wascotextil.vercel.app)

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Client-Warenkorb mit localStorage

## Inhalte

Produkt- und Firmendaten stammen aus dem bestehenden Auftritt [wascotextil.de](https://www.wascotextil.de). Katalogpreise sind Richtwerte. Der Checkout ist eine Bestellanfrage — es gibt keine Online-Zahlung.

## Entwicklung

```bash
npm install
npm run dev
```

```bash
npm run build
npm run lint
npm run typecheck
```
